# Ngamia API integration skill

Use [ngamia-integrations/SKILL.md](ngamia-integrations/SKILL.md) when building or troubleshooting developer applications that use Ngamia models and AI capabilities through a pre-provisioned API key. It points agents to the public [Ngamia developer docs](https://docs.ngamia.cc) and provides a practical end-to-end integration workflow with examples.

The companion [API integration guide](https://github.com/Ngamia-AI/ngamia_api/blob/main/docs/integrations.md) contains the quick start and route map. The complete contract is in the [OpenAPI spec](https://github.com/Ngamia-AI/ngamia_api/blob/main/docs/openapi.yaml).
